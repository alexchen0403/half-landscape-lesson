# 貼一半，畫一半：風景接力

四年級投影用互動美術教材。160 分鐘（4 × 40），20 人、5 組，每人一張四開紙。主要材料：彩色筆、蠟筆、簽字筆；使用供應商現成風景圖。

依序觀察半圖、安排構圖、延續線條、延續顏色、創作與欣賞。包含滑桿、構圖拖曳／方向鍵、接縫對齊、分層示範、試畫、計時與作品自查。無需安裝軟體。

- `index.html`：公開網頁版。末尾已內嵌四件真實風景接畫作品，直接顯示並可點圖放大；整份下載後可離線使用。
- `教案.md`：完整時間分配、教師提問、教室動線、材料與評量。
- `教材底稿.html`：可編修底稿。
- `組裝教材.py`：在老師既有備課工具環境組裝公開版與本機課堂版。四件作品隨 HTML 內嵌，保留原作出處。
- `參考素材/`：CC0 山湖示範照片、來源；圖片已內嵌網頁。
- `課堂參考作品/list.json`：四件真實作品的來源、原圖網址及授權註記。

老師電腦另有 `貼一半畫一半-互動教材.html` 本機課堂版，與公開版內容一致，四件參考作品已內嵌，可離線投影。

操作：頂部導覽或 1–6 跳單元，←→ 跳區塊；R 重置目前互動，L 亮暗，Z 注音，N 老師備註，F 全螢幕。試畫只在頁面暫存，重新整理會清空；正式作品在紙上完成。

四件作品是中心照片向外延伸，不全是精確左右各半；用來比較接線、接色。藝術家作品不作四年級仿作標準。供應商圖片尚未取得，不假定出版社或實際內容，亦未公開上傳供應商教材。
